Add these apps to your server

  • CosmosMarket → Sources → Add Source → https://armanckeser.github.io/selfhost-apps/servapps.json
  • UmbrelApp Store → ⋯ → Community App Stores → add https://github.com/armanckeser/selfhost-apps
  • CasaOS / ZimaOSApp Store → Add Source → https://github.com/armanckeser/selfhost-apps/archive/refs/heads/casaos.zip
  • RuntipiSettings → App Stores → Add App Store → https://github.com/armanckeser/selfhost-apps
  • UnraidNot in Community Apps yet: copy the app's XML from unraid/ in the repo to /boot/config/plugins/dockerMan/templates-user/, then Docker → Add Container
  • PortainerSettings → App Templates → URL https://armanckeser.github.io/selfhost-apps/portainer/templates.json

Source and issues: github.com/armanckeser/selfhost-apps
